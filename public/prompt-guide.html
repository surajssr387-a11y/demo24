01

Kyun Galti Hoti Hai? (Root Cause Samjhein)

⚡ Local vs Vercel Gap

AI Studio me Node.js backend chalta hai jo JSON me save karta hai. Lekin Vercel par sirf static Vite bundle banta hai. Agar code dono jagah sync na ho, toh Vercel purana fallback hi render karega.

📱 Mobile Viewport Crop

Desktop screen wide hoti hai, lekin mobile screen narrow hoti hai. Square photos ke top/bottom crop ho jate hain jab tak unme objectPosition (x%, y%) exact lock na kiya jaye.

💾 Phone Browser Cache

Mobile Chrome aur Safari purana localStorage aur images save kar lete hain. Jab tak code me storageKey ko bump (v26 -> v27) na kiya jaye, phone purana version hi dikhata hai.

02

AI Ko Command Dene Ke 4 Golden Rules

1

Full Context Dein (Clarity Over One-Liners)

Sirf "photo theek karo" mat boliye. Boliye: "Gymnastic photo ka position mobile view me left-align (5%) karo, static fallback me sync karo aur push karo."

2

Hosting Platform Ka Naam Boliye (Vercel)

Hamesha mention karein: "Ye site Vercel static build par chalegi, toh Single Source of Truth follow karo taaki static fallback aur JSON me koi mismatch na rahe."

3

Mobile Framing Hamesha Lock Karwayein

Media changes ke waqt boliye: "Mobile screen par check karke xPosition aur yPosition framing lock karo taaki faces/text crop na ho."

4

Zero-Friction Push Directive

Har prompt ke aakhri me ye sentence fix kar lein: "compile_applet verify karo aur git push origin main kar do."

03

Copy-Paste Master Prompts (1-Shot Success Formulas)

Prompt 1 — Photo / Video / Framing Badalte Waqt

Is [Photo/Video] ko update karo. Iska mobile framing (xPosition, yPosition) check karke desktop aur mobile dono ke liye lock karo. Static fallback (DEFAULT) aur JSON data dono me sync karo, storage version bump karo taaki mobile par turant dikhe, aur git push origin main karo.

Prompt 2 — Ultra Fast & Smooth Performance (60FPS)

Website ki speed aur smoothness optimize karo: Heavy modals ko React.lazy + Suspense se code-split karo, background videos par preload="auto" aur fallback poster lagao, scroll listeners ko requestAnimationFrame se throttle karo, unused code clean karo, aur push origin main kar do.

Prompt 3 — Nayi Website Shuru Karte Waqt (Kickoff)

Mujhe ek [Niche, jaise Dance Studio] website banani hai. Ye Vercel static build par host hogi. Single Source of Truth architecture follow karna taaki static build me koi data mismatch na ho. Tailwind CSS se modern, high-contrast, mobile-first design banao. Heavy modals ko lazy load karo. Page sections: [Navbar, Hero with video, Categories, Achievements, Reviews, Footer]. Sabhi media public folder me rakho aur build test pass karke git push origin main karo.

🎯 1-Shot Golden Formula: "The Trinity Prompt"

Agar aapke paas lamba prompt likhne ka time na ho, toh bas ye 3 keywords prompt me shamil karein:

1. Single Source of Truth JSON aur TS fallback hamesha synced
2. Mobile Framing xPosition & yPosition locked
3. Git Push Verified compilation + main branch
